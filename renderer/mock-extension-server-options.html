    설명
    확장에 든 SonarQube 를 이 기기에서 띄워 지금 프로젝트를 분석하고, 품질 게이트·이슈를 봅니다

    오른쪽 패널의 + 메뉴 › 확장 › SonarQube 로 엽니다. [띄우기] 로 서버를 켭니다 — 처음엔 1분 남짓, 그다음부터 20초 남짓 걸리고 메모리를 약 2GB 씁니다. [분석] 으로 지금 프로젝트를 분석합니다. 범위를 전체 · 폴더·파일 · 내 변경(이 브랜치에서 바뀐 파일과 커밋 안 한 파일)으로 고를 수 있고, 범위 결과는 전체 결과와 따로 보관합니다. 이슈의 파일 경로를 누르면 그 파일이 열립니다. [수정 요청](여러 개는 골라서 한 번에)을 누르면 새 대화가 열리고 수정 요청이 바로 보내집니다 — 덧붙일 말은 그 대화에서 이어서 하세요. 수정은 함께 설치되는 sonarqube-fix 스킬을 따라 해당 부분만, 동작을 바꾸지 않게 고칩니다. 마지막 결과는 서버가 꺼져 있어도 보이고, 확장을 지울 때까지 남습니다. 서버는 이 기기(127.0.0.1)에서만 접속되고 바깥으로 요청하지 않습니다.

    서버 옵션

서버 옵션 — SonarQube 패널의 서버 카드에서 두 체크가 여기로 이사 왔습니다. 데이터는 settings.extensionServers[<id>] 에 있고, server.setOptions IPC 로 씁니다.
